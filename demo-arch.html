線路架構主站點與備援站點、辦公室原圖第 1 頁

依原圖重繪，只換版面，不改連線。由左到右：網際網路 → 主站點 (WAF、負載平衡器、App 叢集) → 備援站點、辦公室；管理交換器同時收 App 叢集與跳板機的管理線，並以 VPN 通道接辦公室。

線色＝用途：對外流量API / 回報管理站點互連主機互連虛線＝備份
框色＝設備歸屬：S 自建M 代管

線路經過的設備線速方向
對外使用者 → WAF → 負載平衡器 → App 叢集 Web ①②1G單向
API負載平衡器 → App 叢集 API ③④1G單向
主機互連App 叢集 ↔ 資料庫、快取；資料庫 (備) ↔ App 叢集 (備)10G雙向
管理App 叢集 SSH ⑥、Agent ⑦ → 管理交換器；跳板機 → 管理交換器1G單向
站點互連資料庫 → 資料庫 (備)，串流複寫10G單向
主站點 → 辦公室管理交換器 ↔ 防火牆 (辦公室)，VPN 通道；遠端人員 → 防火牆；防火牆 → 監控主機1G雙向
備份資料庫 (備) → 備份儲存每日一次單向
注意
  • 原圖右下的區塊沒有標名，本圖暫稱「辦公室」。
  • 線速照原圖線上的標註；原圖沒標的管理線 (SSH、Agent) 依同區交換器規格標 1G。
  • 排程 ⑤ 在原圖沒有對外連線，只在叢集內部執行。

資料來源：demo-network.drawio，第 1 頁「Phase 1」。框色沿用原圖：黃＝S 自建、藍＝M 代管。

線路架構測試環境原圖第 1 頁右側

測試環境與正式環境沒有連線。測試流量 a、b 從 CI 進測試主機；回報 c 經防火牆回 CI；管理網路經防火牆、Internet 給協力廠商。

線色＝用途：對外流量API / 回報管理站點互連主機互連虛線＝備份
框色＝設備歸屬：S 自建M 代管

線路經過的設備線速
測試流量 aCI → 測試閘道 → 測試主機 a測試閘道到測試主機：1G 電
測試流量 bCI → 測試閘道 → 測試主機 b測試閘道到測試主機：10G 光
回報 c測試主機 c → 測試閘道 → 防火牆 → CI測試主機到閘道：10G 光；閘道到防火牆：1G 電
管理測試主機 d (mgmt)、e (Agent)；Mock 服務 f (mgmt)、g (Agent) → 交換器 (管理) ↔ 防火牆 ← Internet ← 協力廠商原圖未標
注意
  • 原圖測試流量 a、b 兩條線穿過測試閘道框，沒有標示是否經過該設備；本圖照原圖畫成穿過 (框內虛線)。
  • 測試主機與 Mock 服務之間的連線，原圖沒有標用途與線速。

資料來源：demo-network.drawio，第 1 頁「測試站點」區。
